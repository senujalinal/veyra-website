# Viora website

The marketing and legal website for Viora, a customizable browser new-tab workspace.

## Included

- Responsive landing page with product showcase, feature comparison, reviews, pricing and FAQ
- Privacy, terms, cookie, refund, licence and support pages
- Search and social metadata
- GitHub Actions checks for every pull request and main-branch update

## Local development

Use Node.js 22 or newer.

```bash
npm install
npm run dev
```

Before accepting payments, connect the pricing buttons to the real checkout URLs and add the legal business name, address, support email, payment provider and jurisdiction to the policy pages.
