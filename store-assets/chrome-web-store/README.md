# Chrome Web Store screenshots

This folder contains the ready-to-upload Veyra screenshots for the Chrome Web Store.

## Upload files

Upload the PNG files in `screenshots/` in their numbered order:

1. `01-wraith-workspace.png`
2. `02-mist-workspace.png`
3. `03-celestial-focus.png`
4. `04-pixel-garden.png`

Each is a full-bleed 1280×800 PNG, the preferred Chrome Web Store screenshot size. They are cropped and optimised from the supplied 26 October 2026 product screenshots; the original files remain untouched in the source screenshots folder.

The website slideshow uses its own 1920×1080 WebP versions in `public/slides/v2/` for fast loading.
